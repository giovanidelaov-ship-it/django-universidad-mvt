
# Proyecto Universidad MVT

**Alumno:** Giovani de la O Vazquez

## Descripción
Proyecto escolar desarrollado con Python y Django utilizando la arquitectura Modelo-Vista-Template (MVT).

## Funcionalidades
- Gestión de cursos.
- Gestión de profesores.
- Gestión de estudiantes.
- Búsqueda dinámica con filtros.
- Operaciones CRUD.
- Autenticación y API REST.

## Tecnologías
- Python
- Django
- SQLite
- Bootstrap
- Git y GitHub
